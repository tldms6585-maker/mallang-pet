# 말랑 키보드 펫 (안드로이드 소스 프로젝트)

**APK가 아닌 Android Studio용 소스 코드입니다.** Android Studio에서 프로젝트 폴더를 열고 Gradle Sync 후 Build > Build APK(s)로 APK를 만드세요. Android SDK 35 및 인터넷을 통한 Gradle 플러그인 설치가 필요할 수 있습니다.

## 실행
1. 빌드한 APK를 안드로이드 휴대폰에 설치합니다.
2. 앱의 '접근성 설정 열기'를 누르고 '말랑 키보드 펫' 서비스를 활성화합니다.
3. 캐릭터가 다른 앱 위에 표시됩니다. 손가락으로 끌어서 이동합니다.
4. 텍스트 입력 변경 알림을 받으면 좌/우 발 그림을 번갈아 표시합니다.

## 프라이버시와 제약
- 텍스트 입력 변경 **이벤트**만 사용합니다. 이벤트의 텍스트, 입력값, 앱 내용은 읽거나 저장하지 않습니다.
- 접근성 서비스 권한은 매우 민감합니다. 직접 빌드하고 코드 확인 후 활성화하세요.
- 앱마다 접근성 이벤트 전달 여부가 달라 반응하지 않을 수 있습니다. 일부 비밀번호 입력 등은 이벤트가 제한됩니다.
- 키 하나당 이벤트 하나가 보장되지는 않습니다. 실제 물리 키 감지가 아닌 **텍스트 변경 이벤트 기반**입니다.
- 앱 설치 후 접근성 서비스가 제한되는 경우, 기기 설정에서 앱의 제한된 설정 허용이 필요할 수 있습니다.
- 앱 내부 이미지 교체 UI는 포함하지 않았습니다. `app/src/main/res/drawable-nodpi/`의 사진 3장을 교체 후 다시 빌드하세요.

## 앱 아이콘
사용자가 제공한 하늘색 캐릭터 이미지를 앱 런처 아이콘으로 설정했습니다.
